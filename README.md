**主要功能：**
- 精确利润计算：考虑手续费、印花税等所有交易成本
- 多种交易模式：支持买入做T和卖出做T两种操作
- 实时收益率显示：直观展示投资回报率
- 成本分析：详细展示各项交易费用

**适用场景：**
- 股票日内T+0交易
- ETF套利操作
- 可转债T+0交易
- 其他短线交易策略

**计算项目：**
- 买入成本（含手续费）
